01 — A CONTROLLED SEQUENCE

Know what’s there.
Then move it forward.

Version values can hide in build metadata and Python files. jiggle_version reads common declaration forms, verifies agreement, and makes an explicit change when you ask for one.

01SCAN

Discover

Find version declarations in pyproject.toml, setup.cfg, static setup.py, and Python modules.

jiggle_version inspect
02VERIFY

Check agreement

Catch drift in CI or locally with a read-only command. Optionally compare the result with the nearest Git tag.

jiggle_version check
03PREVIEW

Plan the bump

Choose a PEP 440 or SemVer increment. Dry-run mode shows the result without writing files.

jiggle_version bump --dry-run
02 — TRY THE READ-ONLY PATH

Start with
a quick check.

The default workflow keeps Git operations off. Run a check, inspect the agreed version, and preview the next patch.

Explore the CLI ↗
terminal / project-root
$ jiggle_version check
# Verify that discovered sources agree
$ jiggle_version print
# Print the agreed version
$ jiggle_version bump --increment patch --dry-run
# Preview changes without writing
